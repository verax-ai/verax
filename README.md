# Verax

The accountable agent body.

Any brain that speaks MCP can drive it. Every tool call passes a gate,
leaves a signed decision record before anything runs, and produces an
effect row afterwards that is reconciled against the record. A refusal is
recorded the same way as an approval. The body opens only when its
authorization is configured; there is no default token.

Status: skeleton, no release. What the tree carries and what remains
unproven is stated in `docs/STATUS.md` once that file exists; until then,
nothing here is a claim.
